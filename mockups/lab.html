Phobos Lab mock-up

The whole Lab layout, in look A Control room (docs/UI_STYLE.md). S1 builds only the Live tab. The other five tabs are here so later slices fill in a layout you have already approved. Each frame is 400 px wide, the first target width; on a phone the row scrolls sideways. The controls are drawn, not wired: each frame shows one state, side by side.

Charts and numbers are computed in this page or by a throwaway script written from the spec's plant, PI and test definitions (docs/specs/first-usable.md "Design"). They are measurements of that script, not of repo code, which does not exist yet. S2 to S4 replace them. Values that need a trained net (M3) show as "–".

Done. Numbers from the throwaway script.

Found while computing these:

On 1.00→1.75 the retuned PI is worse than the fixed one (11.79 against 9.74 m·s). Retuning raises Ti there, which slows the integral. Total: fixed 50.94, retuned 47.58 m·s. The spec's J2 assertions still hold: 0.50→0.25 retuned 2.28 < 0.8 × 4.11, dist@1.00 equal, noise changes IAE by at most 0.08 m·s.

Valve travel is about 10.2 to 11.0 per segment for both PIs. With Kp = 1, ±0.005 m of sensor noise moves the valve every 0.1 s step, so noise makes up most of that travel. D-011's "valve travel at most 2× the fixed PI's" will mostly measure how much the net amplifies noise. This is not a problem for S1. I'll raise it again before S6.
