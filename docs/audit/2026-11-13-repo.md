### F6 AGENTS.md's integer-only rule doesn't match the code it names

- **Rework if left:** low
- **Effort:** S
- **Evidence:** `AGENTS.md:28` "`Math.floor(x / 2 ** n)`"
- **Case:** Since D-017, `shr` in `src/num/fixed.ts` divides by a stored table, `POW2[n]`. `docs/NUMBERS.md` line 9 gives the same old expression. The rule also says "the runtime path" without naming it. `src/num/` also holds offline code that uses `Math.round`, `Math.tanh` and `Math.exp` (quantise, table generation, table errors). Someone checking the rule against `src/num/` would find what look like breaches, and the Vulcan exporter work needs a clear boundary.
- **Fix:** Name the runtime path in the rule (`src/runtime/`, `src/num/fixed.ts` and the table lookups), say that the quantise and generation files are offline, and show `shr` as a floor divide by a stored power of two in AGENTS.md and NUMBERS.md.
